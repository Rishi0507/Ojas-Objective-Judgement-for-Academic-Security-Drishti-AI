✨ HOW VIDEO PLAYBACK WORKS:

1. FULL VIDEO STREAMING
   • Plays the entire CCTV video file
   • Source: clips/04.CCTV Candidate Talking.mkv
   • Streams via /api/stream endpoint
   • Supports range requests for seeking

2. EVENT TIME RANGE
   • Video starts at event start time
   • Example: Event 1 starts at 0:00, Event 4 starts at 1:00
   • Auto-pauses when reaching event end time
   • Time range shown in top-right corner

3. CONTROLS
   • Play/Pause: Click button below video
   • Seek: Drag the seek bar
   • Time display: Shows current position
   • Auto-restart: If at end, clicking Play restarts from event start

4. SMART FEATURES
   • Event-scoped: Only shows the relevant time segment
   • Auto-pause: Stops at event end boundary
   • Smooth seeking: Jump to any point in the event
   • Real-time display: Current time updates as video plays

🐛 TROUBLESHOOTING:

Issue: Video not loading (black screen)
Fix:
  • Check video file exists: clips/04.CCTV Candidate Talking.mkv
  • Check browser console (F12) for errors
  • Verify /api/stream endpoint is working
  • Try different browser (Chrome/Firefox/Edge)

Issue: Video loads but won't play
Fix:
  • Check browser codec support (MKV may need conversion)
  • Convert to MP4 if needed: ffmpeg -i input.mkv output.mp4
  • Check browser allows video autoplay

Issue: Controls not working
Fix:
  • Hard refresh browser (Ctrl+Shift+R)
  • Clear browser cache
  • Check JavaScript console for errors

Issue: Wrong time range displayed
Fix:
  • Verify event data in public/api/events.json
  • Check event start/end times match expectations
  • Re-run integration: .\run_integration.bat
